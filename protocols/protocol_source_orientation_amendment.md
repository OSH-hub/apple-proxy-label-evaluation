# Source orientation and authorized I/O worker amendment

No v4 model had been fitted when these source defects were inspected. The original extraction uses `PIL.Image.open(...).convert('RGB')` without applying EXIF orientation. Some JPEG raw rasters have width/height 4032×3024 while the associated JSON coordinate system is 3024×4032. This produced out-of-bounds bbox audit failures, and an in-bounds bbox alone cannot exclude a wrong orientation.

Every selected image is now decoded and normalized with `PIL.ImageOps.exif_transpose` before bbox handling, including EXIF transformations that preserve width/height. The normalized dimensions must exactly match both JSON dimensions. Missing or inconsistent EXIF information does not authorize guessed rotation, scaling or bbox clipping. Such mismatches remain failures requiring investigation. Positive bboxes must lie wholly inside the normalized image. The retained padded crop includes the complete annotated bbox before the usual model augmentation/center crop. Raw JPEG SHA-256, raw dimensions, EXIF tag, normalized dimensions, bbox, padded box and final crop SHA-256 are retained privately. Orientation-by-tag counts and a stratified visual sample are reported separately from the complete algorithmic audit.

The remote SMB connection remained a bottleneck after offset scheduling. Source reading and crop construction were therefore moved to the same author's Windows workstation, accessing the same NAS archives and privately transferring the 21,443 selected JSON files. Raw JSONs, images, crops and row-level linkage are kept in a temporary directory outside the cloud-synchronized project directory. Only the final corrected crops and internal provenance move to the existing authorized remote research project. All model fitting, predictions and primary analysis remain on the remote server. The worker records its actual Pillow/JPEG versions; no cross-version byte identity is presumed.

The final crop directory is `private/crops_v4_oriented`. Previous partial extraction attempts are preserved separately and are not training inputs. The representative image choice, single-row label policy, original v2 group allocation, six seeds/schemes and 40-epoch settings remain unchanged. The historical valid-crop assumption is replaced by full re-extraction with explicit orientation. Earlier v2/v3 outputs are not modified or presented as corrected results.
