# P1 source and crop correction protocol — 26 October 2026

This amendment is written before inspecting any v4 model result. It follows discovery of cross-row label filling and 1,807 missing-bbox full-frame fallbacks. Previous v2/v3 analyses have already been inspected; this is a post hoc correction, not a prospectively registered validation. Original data and v2/v3 outputs remain unchanged.

1. Preserve all 21,443 historically selected representative image records and the exact v2 tree and cultivar–farm-combination assignments. Reconstruct the original representative-image choice (lowest angle, first encountered tie). Read image name, NIR, destructive/reference sugar and bbox together from that image's own JSON. Normalize a trailing `.json.jpg` only for source-image lookup and normalize `.json.json` for JSON lookup. Never fill labels from another row or infer H/A physical identity.
2. Audit and regenerate every selected crop from the source ZIP. Verify the selected manifest row against its JSON, decode each source image, require a finite positive bbox wholly inside the source image, include that bbox with the original 5% padding, resize only if the longer side exceeds 512 pixels, and save JPEG quality 90. A missing/invalid bbox is a recorded failure, never a full-frame fallback. Retain private JSON/image/crop hashes and transformations. Full validation is algorithmic geometric/source validation; it does not independently prove every provider annotation targets the intended physical fruit.
3. Preserve the historical 15,267 proxy-only pool as the only fitting/selection pool. Reference-pool records remain reference records; if their selected image's original row lacks NIR or sugar, exclude them from reference evaluation and do not transfer them into training. Use the complete original-row labels even if they differ from the historical cross-row labels. Report exclusions and label changes. Primary analysis uses this corrected same-row complete cohort; a sensitivity cohort additionally requires only one distinct NIR across the historical composite key's rows. This composite key is not proof that H/A images depict one physical fruit.
4. Freeze splits to the saved v2 manifests before exclusions. Two schemes, three seeds (0/1/2), 40 epochs, ImageNet ResNet50, dropout 0.2, heteroscedastic mean/logvariance head, AdamW head 1e-4/backbone 1e-5, weight decay 1e-4, cosine schedule, first 5 Huber warm-up epochs, batch128, four workers, two computation threads. Only proxy fitting targets set normalization; only proxy selection MAE chooses checkpoints. GPU0 runs tree seeds; GPU1 runs combination seeds. No other jobs are interrupted. No seed or model is dropped for unfavorable results.
5. Recompute deterministic and 20-pass MC predictions for calibration/test sets. Freeze BN running statistics while dropout is active. Assert deterministic repeat agreement, nonzero dropout variation, unchanged BN buffers, and p=0 repeat agreement. Retain checkpoints, histories, pass arrays and hashes privately. Retry only documented implementation/resource failures, not unfavorable scientific results.
6. Recompute original primary MAE, NIR discrepancy, fitting global/cultivar baselines, paired differences, uncertainty rankings, tie-aware capture at 5/10/20%, retained error, and Gaussian/proxy-/reference-residual calibrated interval coverage at 68/90/95%. Use fixed bootstrap seed 20261026, 5,000 accuracy/coverage bootstrap replicates and 1,000 Spearman replicates. Tree evaluation resamples trees. Combination evaluation reports farm-cluster uncertainty as primary, with combination-cluster estimates separately; the same farm can occur in development/test. Five test farms provide weak cluster precision. No independence/generalization claim follows from either estimate.
7. Recalibrate within each reference cohort (including strict sensitivity), preserving separate calibration/test roles. Model fitting is not rerun by cohort. Between-seed variance plus mean aleatoric variance defines the previous total SD; MC dropout remains a distinct score. Do not silently add MC variance to change the estimand.
8. Historical LOCO results were produced with the defective preprocessing and are not corrected by this experiment. Omit them from new confirmatory results and explicitly identify their exclusion. A future corrected LOCO or genuine farm-disjoint experiment requires its own documented protocol and full rerun; no old result is relabelled as corrected.
9. Publish aggregate tables/figures/code, not original image names, object keys, individual labels/predictions, checkpoints, ZIP entries or row-level hashes. State AI Hub dataset 490, unverified provider label release, unknown H/A physical equivalence, observational proxy/reference distinction, and limits of external validity. Update manuscript, supplement and cover only from actual completed results.
